# MolRAG

## MolRAG: Unlocking the Power of LLMs for Molecular Property Prediction

This repository contains the official code for the paper:

**[MolRAG: Unlocking the Power of LLMs for Molecular Property Prediction](https://aclanthology.org/2025.acl-long.755/)**

> **MolRAG** proposes a Retrieval- Augmented Generation framework integrating Chain-of-Thought reasoning for molecular property prediction..
